ABOUT ME

The Engineer Behind the Work

I'm Darryl — a full-stack and mobile engineer based in Los Angeles. I've spent 15+ years going from freelance web work to leading engineering on production apps used by real people every day. Most of that time has been at ISBX, where I've grown from building native iOS apps to architecting entire product platforms.

I specialize in the layer where mobile, real-time systems, and backend infrastructure meet. That's not a common combination — most engineers live on one side or the other. I'm comfortable owning a Native iOS app, or React Native app, the NestJS API it talks to, the AWS infra it runs on, and the Terraform config that deploys it.

What makes me different is that I've done this across wildly different domains: IoT and Bluetooth hardware, live event management, sports platforms, social discovery, electric vehicles. The domain always changes. The discipline of shipping clean, maintainable, production-ready software doesn't.
